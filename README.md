# 🌍 AI Travel Agent

An AI-powered Travel Agent built with **FastAPI**, **LangChain**, and **LangGraph** that helps users plan trips and answer travel-related questions through an interactive chat interface.

## 🚀 Live Demo

🌐 **Live Application:** https://ghanshyam6032.github.io/AI-Travel-Agent/

---

## ✨ Features

- 🤖 AI-powered Travel Assistant
- 💬 Interactive Chat Interface
- 🌍 Travel Planning & Recommendations
- 🗺️ Destination Suggestions
- 🧠 Agent-based Workflow
- ⚡ FastAPI Backend
- 🎨 Responsive HTML, CSS & JavaScript Frontend
- 🐳 Docker Support
- ☁️ Railway Deployment

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Ghanshyam6032/AI-Travel-Agent.git

cd AI-Travel-Agent
```

### 2. Create a Virtual Environment

```bash
python -m venv .venv
```

### Windows

```bash
.venv\Scripts\activate
```

### Linux / macOS

```bash
source .venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Create a `.env` File

```env
GROQ_API_KEY=your_groq_api_key

AMADEUS_CLIENT_ID=your_amadeus_client_id
AMADEUS_CLIENT_SECRET=your_amadeus_client_secret
```

### 5. Run the Application

```bash
python main.py
```

---

## 🐳 Run with Docker

### Build Docker Image

```bash
docker build -t ai-travel-agent .
```

### Run Docker Container

```bash
docker run -p 8000:8000 --env-file .env ai-travel-agent
```
