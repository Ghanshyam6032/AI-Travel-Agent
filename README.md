# 🌍 AI Travel Agent

An AI-powered Travel Agent built with **FastAPI** that helps users plan trips and answer travel-related questions through an interactive chat interface.

## 🚀 Live Demo

🌐 **Live Application:** https://ai-travel-agent-production-f308.up.railway.app/

---

## ✨ Features

- 🤖 AI-powered travel assistant
- 💬 Interactive chat interface
- 🗺️ Travel planning and recommendations
- 📍 Destination suggestions
- 🧠 Agent-based workflow
- ⚡ FastAPI backend
- 🎨 Responsive HTML, CSS & JavaScript frontend
- 🐳 Docker support
- ☁️ Deployed on Railway

---

## 🛠️ Tech Stack

### Backend

- Uvicorn

### AI

- LangGraph
